# TiendaBarrio 🛒

¡Bienvenido a **TiendaBarrio**! Una plataforma web de comercio electrónico diseñada para acercar los comercios de cercanía a los vecinos, especializada en la venta de accesorios, indumentaria y productos para el hogar.

## 📦 Categorías Principales

* **Ropa**: Prendas modernas y cómodas para el día a día.
* **Accesorios**: Complementos ideales para resaltar cualquier estilo.
* **Hogar**: Artículos de decoración y utilidades indispensables.

## 🚀 Características del Proyecto

* **Interfaz Moderna**: Diseñada estéticamente con componentes de Bootstrap.
* **Diseño Responsivo**: Adaptado para celulares, tablets y computadoras (Mobile-First).
* **Navegación Simple**: Estructura de páginas interconectadas para una experiencia de usuario fluida.

## 🛠️ Tecnologías Utilizadas

* **HTML5**: Estructura semántica del sitio web.
* **CSS3**: Estilos personalizados y diseño visual.
* **Bootstrap v5**: Framework para diseño responsivo y componentes preestablecidos (botones, menús, tarjetas).

## 🔧 Cómo Ejecutar el Proyecto Localmente

No necesitas instalar dependencias ni usar terminales para ver este proyecto. Sigue estos simples pasos:

1. **Descargar o clonar el proyecto**
   ```bash
   git clone https://github.com
   ```
   *(O simplemente descarga el archivo ZIP desde GitHub y descomprímelo).*

2. **Abrir el proyecto**
   * Ve a la carpeta raíz del proyecto.
   * Haz doble clic en el archivo `index.html`.
   * El sitio se abrirá automáticamente en tu navegador web predeterminado.

## 📁 Estructura de Archivos

```text
TiendaBarrio/

├── index.html          # Página principal (Home)

├── css/
```
